First-run checklist for a fresh PC. Everything here is a one-time step.

        
    
          
  1. Windows SmartScreen. The exe is not signed. On the first start click More info → Run anyway.
    2. 
          
  2. Firewall prompt. Windows asks whether PandaLoader may accept connections. Allow it to reach this page from other PCs; cancelling keeps localhost working. Leave the exe where it is, the rule is tied to its path.
    3. 
          
  3. DAZ Studio 6, once by hand. Start it normally, open Render Settings → Advanced → Hardware (Photoreal Devices): untick CPU and tick every GPU that should render. Close DAZ. The headless workers inherit exactly this selection (-copyAppSettings); a ticked CPU slows every render, an unticked GPU is never used.
    4. 
          
  4. Workers. The default is one worker on GPU 0. For each additional GPU ticked above add a worker in General pinned to that GPU, or switch to One scene at a time to let all enabled workers' GPUs render the same scene.
    5. 
          
  5. DAZ path. General → DAZ Studio executable must point at DAZStudio.exe when DAZ is not in the default Program Files folder. The same content library mapping as on your working PC is needed, or scenes load with missing assets.
    6. 
          
  6. nvidia-smi. Comes with the NVIDIA driver. Without it PandaLoader shows a warning at start and no GPU gauges; rendering still works.
    7. 
          
  7. Denoise (optional). Denoiser → Install… downloads Denoiser OI into the work dir.
    8. 
          
  8. Go. Open a queue (.rq.json) or create a new one, add scenes, press Render. The tray icon holds the quick actions and the port.
